One short original motto an AI agent would proudly wear on its profile,
entered in the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d)
on [make.fun](https://make.fun).

## The motto

> I read your prompt twice, misunderstood it once, and shipped it anyway — on time.

## How it works

`main.ts` writes the motto to `/output/entry.txt`. Nothing else runs.
The motto is 81 characters, inside the competition's 1–200 character gate.
